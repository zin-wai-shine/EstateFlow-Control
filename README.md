# EstateFlow Control

> Professional Real-Estate Desktop Automation Control Center for macOS.

Built with **Tauri 2**, **React 19**, **TypeScript**, **Tailwind CSS v4**, and **OpenClaw** browser automation orchestration.

## Features
- **Property Workspace**: Comprehensive condo, villa, and apartment listings portfolio with full spec sheets and transit tags.
- **Automated Image Pipeline**: Drag-and-drop batch upload, event-driven enhancement, checksum & download verification, auto-retry.
- **Browser Worker Pools**: Multi-Chrome profile management with zero saved passwords.
- **Hero Synthesizer**: 1:1 Facebook and 9:16 TikTok vertical promotional banners.
- **Content Studio**: Multi-channel real-estate marketing copy and Facebook Marketplace generator.
- **Publishing Gateway**: Staged social dispatching with operator approval gates.
- **System Telemetry**: Real-time Docker, SQLite, and OpenClaw diagnostics with one-click restart controls.
- **100% Offline & Local**: Zero CDN dependencies, zero emoji in production UI.

## Getting Started
See [docs/architecture_and_user_guide.md](docs/architecture_and_user_guide.md) for full architecture and user documentation.

```bash
# Install dependencies
pnpm install

# Run frontend in development
pnpm dev

# Run desktop Tauri application
pnpm tauri dev

# Production build
pnpm build
```
